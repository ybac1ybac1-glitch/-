# P2.2 Strategy A implementation report

本 PR 实现单股、只读的策略 A 扫描器，不启动全市场扫描，不写 SQLite，也不改变 V3.1 或策略 B。

## 实现范围

|规则|实现状态|输出|
|---|---|---|
|A01 交易区间|已实现|80 个有效交易日前置窗口、上下沿、宽度、斜率、持续天数|
|A02 供应减弱|已实现|回落段与基准段的成交量、日内波动比较|
|A03 Spring|候选已实现|跌破支撑并收回；缺少历史涨跌停/停牌字段时保留缺失字段，不能确认买点|
|A04 Spring 后测试|候选状态机起点已实现|15 日窗口和支撑保持条件；历史状态持久化仍由后续信号层接入|
|A05 SOS|候选已实现|T-1 压力、20 日量能基准、收盘位置|
|A06 LPS|候选已实现|仅在本次扫描存在 SOS 时检查缩量回踩，不能凭单日回踩确认|
|A07 努力与结果|背景证据|不触发买入|
|A08 量价背离|背景预警|不判定顶底|
|A09 派发风险|风险提示|至少两个独立工程条件才标高风险，不是卖出指令|

所有返回均为现有 Evidence，规则版本为 A-P2.2-0.1，阈值版本 A-E4-2026-01。E4 表示工程研究假设；没有把它们宣称为书本固定阈值。

## 数据安全

输入先按 trade_date <= asof_date 截断，清除无效日期、非正价格和缺失 OHLCV；每只股票使用自身有效交易日数。少于 20 日或少于 80 日区间窗口时返回 INSUFFICIENT_DATA。没有使用未来数据、复权因子、涨停价或停牌状态的替代值。

## 仍受限制的能力

历史涨跌停规则、停牌、ST 时点、复权因子、分钟/竞价数据未接入，因此 Spring、测试和突破确认仍是候选/保守证据。A04 的跨日状态重放需要由 signals 层按逐日输入驱动；本 PR 不执行真实回测或全市场扫描。
