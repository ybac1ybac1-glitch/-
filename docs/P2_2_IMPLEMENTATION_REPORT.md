# P2.2 Strategy A implementation report

本轮在 PR #4 上修复了交易逻辑，仍为单股只读研究扫描，不写 SQLite、不执行全市场扫描。

## 规则与 Evidence 对照

|规则|状态与证据|
|---|---|
|A01|使用 T-1 的 80 个有效交易日；10/90 分位数上下沿、宽度、斜率、稳定性和上下沿反复测试数。斜率过低、宽幅或下降中继不会成为区间候选。|
|A02|成交量收缩必须同时结合回落幅度或波动收敛，并要求成交额为正，避免把低流动性误判为供应减弱。|
|A03|只有有效 A01 区间才寻找 Spring；支撑来自 Spring 前窗口；缺少涨跌停、停牌、复权字段只输出候选并记录缺失。|
|A04|逐日回放历史 Spring，在之后 1–15 个有效交易日检查缩量、守支撑和破位失效；不引用未来日期。|
|A05|逐日寻找有效压力突破、量能倍数和收盘位置；没有有效区间时不确认结构。|
|A06|仅在历史 SOS 之后扫描后续交易日缩量回踩，记录 SOS/LPS 日期，跌破支撑标记失效，不允许同日双重解释。|
|A07|努力与结果只输出背景 Evidence。|
|A08|量价背离只输出预警 Evidence。|
|A09|风险条件分别记录上升趋势、高量下跌收盘、宽幅波动；至少两项才提示高风险。|

所有阈值集中在 PARAMS，版本为 A-E4-2026-02，证据等级为 E4 工程研究假设，不宣称为书本固定公式。所有结果统一使用 Evidence 状态协议。

## 数据边界

输入按 trade_date <= asof_date 截断，并按每只股票自身有效交易日清理。零价格、异常价格、无效日期和缺失 OHLCV 不会被填充。未接入历史涨跌停、停牌、ST 时点、复权因子和分钟/竞价数据，故不能产生 CONFIRMED 或可成交买点。策略 A 与策略 B、V3.1 完全隔离。

测试新增横盘、下降趋势、下降中继、宽幅、Spring 跨日测试、SOS 后 LPS、无先前 SOS、未来隔离、零成交量和幂等反例。
