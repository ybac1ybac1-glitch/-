# P2.1 策略 A 数据依赖矩阵

当前用户本机已验证约 120 个全市场交易日；代码/CI 不读取用户数据库。全市场日期数不代表每只股票有效长度，规则必须按 `ts_code` 截至信号日计数。

|数据|当前状态|可支持规则|缺口/处理|
|---|---|---|---|
|trade_date、OHLCV|已有|A01、A02、A03、A05、A07、A08 的日线候选|每只股票窗口不足返回 INSUFFICIENT_DATA|
|amount|已有|流动性、努力/结果、区间过滤|缺失不能通过|
|turnover_rate|P1 已迁移/回填|流动性和供应减弱辅助|缺失标记 missing_fields|
|120 日历史|全市场覆盖；个股需单独计数|约 60–120 日区间候选、Spring/SOS 初筛|A01 80 日勉强支持；不能支持 240 日长形态|
|240+ 日历史|未保证|长期背景、圆弧等|本阶段只评估扩展方案，不回填|
|adj_factor|未接入|复权口径一致性、长期形态|待数据源/权限确认|
|stk_limit/历史涨跌停价|未接入|Spring/SOS 风险、不可成交回测|不能用代理值冒充历史规则|
|历史 ST/停牌/上市状态|未完整缓存|信号排除、时点回放|缺失时规则待确认|
|分钟/竞价/Level2|未接入|盘口承接和盘中确认|不能量化，返回 NEEDS_INTRADAY|
|指数/板块/题材|不属于 A 必需输入|背景增强|不作为 A 信号必备字段|

建议数据方案：先保留现有 120 日 SQLite；P2.2 前评估增量至 240/300 个真实交易日，按交易日批量、60 次/分钟限流、断点续传，迁移前备份，不在 P2.1 自动执行。
